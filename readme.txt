# Axis Folio

**Axis Folio** is a lightweight, high-performance hybrid plugin designed to bring stunning, responsive masonry layouts to your WordPress site. Whether you are building a professional portfolio, a creative gallery, or a dynamic showcase, Axis Folio provides a seamless experience for both **Gutenberg** and **Elementor** users.

---

## 🚀 Key Features

* **Hybrid Compatibility:** Built natively to function perfectly in both the Gutenberg Block Editor and the Elementor Page Builder.
* **True Masonry Layout:** Automatically arranges your content into a clean, Pinterest-style grid that optimizes space and visual appeal.
* **Drag-and-Drop Interface:** Easily reorder and manage your portfolio items with an intuitive, user-friendly drag-and-drop workflow.
* **Lightweight & Fast:** Engineered for speed. Axis Folio is built with clean code to ensure your site remains fast and search-engine friendly without unnecessary bloat.
* **Simple Setup:** No steep learning curve. Install, activate, and start building your grid in minutes.
* **Responsive Design:** Your masonry layout will automatically adapt to any screen size, ensuring a perfect look on desktops, tablets, and mobile devices.

## 📦 Installation

Installing Axis Folio is quick and simple. You can install it via the WordPress dashboard or via FTP.

### Method 1: WordPress Dashboard (Recommended)

1. Download the `axis-folio.zip` file from your source.
2. Log in to your WordPress Admin dashboard.
3. Navigate to **Plugins > Add New**.
4. Click the **Upload Plugin** button at the top.
5. Choose the `axis-folio.zip` file and click **Install Now**.
6. Once installed, click **Activate Plugin**.

### Method 2: FTP/SFTP Upload

1. Unzip the `axis-folio.zip` file.
2. Connect to your server using an FTP client (like FileZilla).
3. Upload the `axis-folio` folder to your `/wp-content/plugins/` directory.
4. Log in to your WordPress Admin dashboard.
5. Navigate to **Plugins > Installed Plugins**.
6. Locate **Axis Folio** and click **Activate**.

## 🛠 How to Use

### For Gutenberg Users

1. Open any page or post.
2. Click the **(+)** block inserter icon.
3. Search for **"Axis Folio"** and insert the block.
4. Upload or select your images and content directly within the block settings.

### For Elementor Users

1. Open the Elementor editor.
2. Search for the **"Axis Folio"** widget in the sidebar.
3. Drag and drop the widget onto your canvas.
4. Customize your layout, spacing, and styling using the Elementor control panels.

## 📋 Requirements

* WordPress 6.0 or higher.
* PHP 7.4 or higher.
* Elementor (Optional, only if using the Elementor feature).
